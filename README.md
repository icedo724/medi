## 데이터 보안 및 익명화 
본 프로젝트는 실제 기업 현장에서 수행된 과제이나, **계약에 따라** 다음과 같은 조치를 취했습니다.

1.  **데이터 익명화:** 모든 거래처정보와 기타 민감데이터 등은 가상의 데이터로 대체되었습니다.
2.  **스키마 표준화:** 원본 데이터베이스의 한글 테이블명(예: `[회사명]거래처현황`)은 영문 표기(예: `client_info`)로 변경하여 코드 가독성을 높였습니다.
3.  **민감 정보 제거:** API Key 및 내부 서버 접속 정보는 환경 변수(`.env`)로 분리하여 코드에 노출되지 않도록 처리했습니다.

## 주요 업무
### 거래처 데이터 보강
- 연락처·주소 등 기초 정보만 존재하던 내부 거래처 데이터에 건강보험 요양기관 공공데이터를 암호화된 요양기호 기준으로 연동하여 인사이트 도출 가능한 수준으로 확장
- 공공데이터 API 호출 구조에 따라 기관 기본정보 / 병상 정보 / 의사 정보 / 간호사 정보로 스키마를 분리 설계하고 향후 DB 구축의 기준 틀로 제시
- 공공데이터 제공 방식 및 갱신 주기 차이를 반영한 분리 설계로 데이터 정합성 유지 방안 제안

### 등급 재조정 방안 제시
- 2년간의 거래 이력 데이터를 기반으로 ABC 분석·RFM 분석을 적용해 기존 거래처 등급 체계를 데이터 기반으로 재분류
- 카이제곱 검정을 통해 재분류된 등급 간 요인 유의성을 검증하여 방안의 통계적 타당성 확보
- 기존 주관적 기준의 등급 체계를 정량 지표 기반으로 전환하는 방법론 제시
